feat(p4): Tauri build pipeline (GH Action + R2 signed URL)

P4 deliverables (Tauri Build Pipeline):
- src-tauri/: Tauri 2.x app skeleton
  - Cargo.toml: Rust deps (tauri 2, serde, anyhow)
  - tauri.conf.json: window, bundle config
  - src/main.rs: entry point
  - src/lib.rs: tauri::command handlers (get_tool_info, verify_license, ping)
  - capabilities/default.json: default permissions
  - .gitignore: target/, gen/
  - README.md: customize guide
- .github/workflows/build-tauri.yml: GH Action
  - workflow_dispatch trigger with inputs (build_id, tool_id, version, callback_url, webhook_secret)
  - Setup Rust + Node + Tauri CLI
  - Linux build + test (MVP — Windows .exe in P4.5 with Windows runner)
  - Callback POST to Worker /api/forge/webhook/built
  - Real R2 upload planned (P4.5)
- src/forge/build_orchestrator.py: trigger GH Action via API
  - workflow_dispatch call with build_id, tool_id, version
- src/forge/r2_uploader.py: R2 signed URL generator (S3 v4)
  - generate_signed_url: 7-day expiry
  - build_r2_path: <tool_id>/<version>/setup.exe
- src/forge/webhook.py: GH Action callback handler
  - verify_webhook_secret: constant-time check
  - handle_build_complete: update builds + handoff + tools with binary URL

  - POST api forge webhook built     Handle GH Action callback (X-Webhook-Secret)
