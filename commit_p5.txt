P5 Helper agent — Telegram-based customer support + owner reports.

NEW: src/lib/telegram.py — Telegram Bot API client
  - send_message, send_to_owner, set_webhook, get_me, parse_update
  - Graceful: returns ok=False on missing token (no exceptions)
  - Auto-handles API errors, timeouts, network failures

NEW: src/helper/__init__.py — auto-reply + daily report
  - handle_message(update, env): process Telegram Update, send reply
    - Commands: /start, /help, /order, /license, /tools, /contact
    - Non-command: friendly fallback (no spam replies)
    - All replies in Vietnamese (target audience)
  - send_license_to_customer(): called by SePay webhook after payment
    - Sends license key to customer's Telegram if customer_telegram is numeric
    - Skips @username (can't resolve to chat_id)
  - daily_report(env): 22:00 Saigon daily, sends stats to owner
    - Orders count, paid count, revenue, new licenses
    - Error counts (error/warn) from KV monitoring log

NEW: src/handlers/telegram.py — webhook endpoints
  - POST /api/telegram/webhook  — receives Telegram Updates
  - POST /api/telegram/setup    — register webhook URL (admin only)
  - GET  /api/telegram/status   — check bot config (admin only)
  - Optional TELEGRAM_WEBHOOK_SECRET for X-Telegram-Bot-Api-Secret-Token

INTEGRATION:
  - src/handlers/scheduled.py: cron 0 15 * * * now runs daily_report() (was stub)
  - src/handlers/payment.py: sepay_webhook calls send_license_to_customer()
    after successful license activation (best-effort, never fails webhook)
  - src/router.py: imports telegram handler so route registers

OWNER SETUP STEPS (documented in wrangler.jsonc + handler docstring):
  1. Create bot via @BotFather, get token
  2. wrangler secret put OWNER_TELEGRAM_BOT_TOKEN
  3. wrangler secret put OWNER_TELEGRAM_CHAT_ID  (owner's numeric chat_id)
  4. Optional: wrangler secret put TELEGRAM_WEBHOOK_SECRET
  5. Call POST /api/telegram/setup with {webhook_url: "https://..."}
  6. Talk to bot: send /start, /help, /tools
