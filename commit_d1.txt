fix(d1): wrap D1 binding to convert pyodide JsProxy → native Python

CF Python Workers returns D1 prepared statement results as
pyodide.ffi.JsProxy objects. Direct iteration / .get() access from
Python raises:
  TypeError: 'pyodide.ffi.JsProxy' object is not iterable
  AttributeError: 'JsProxy' object has no attribute 'get'

This blocks all D1-touching endpoints (store, scout, architect,
forge, builder, payment, etc.) with HTTP 500.

Fix: src/lib/d1.py shim. wrap_db(db) returns a _D1Wrapper whose
.prepare() returns a _WrappedStatement. first() / all() / run() on
the wrapped statement auto-convert JsProxy rows into native Python
dicts / lists via JsProxy.to_py() (with manual keys-iteration
fallback for cases where to_py() isn't supported).

Applied at worker entry (on_fetch + on_scheduled) — every handler
reading env.DB gets the wrapped version transparently. No changes
needed in the 22 call sites that use db.prepare().bind().all().

Idempotent and safe to call per-request. Lightweight and stateless.
